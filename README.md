# Fran Mondaca — Profile

Personal profile website: a conversational CV ("Ask me") plus a full profile view, in English, Spanish and Catalan.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `fran.webp` — portrait for the Ask view
- `fran-laptop.webp` — portrait for the Profile view

Edit the prepared answers in the `QA` array and the dimensions in `DIMS` inside `index.html`.
